# Portfolio de Lautaro Denis

Sitio web personal publicado con GitHub Pages.

**[Ver el portfolio](https://ldenis06.github.io/portfolio/)**

## Estructura del proyecto

- `index.html`: página principal del sitio.
- `styles.css` y `overrides.css`: hojas de estilo.
- `favicon.svg`: icono del sitio.
- `flag-es.svg` y `flag-us.svg`: recursos gráficos de banderas.

## Ver el sitio localmente

1. Cloná el repositorio:

   ```sh
   git clone https://github.com/Ldenis06/portfolio.git
   cd portfolio
   ```

2. Desde esa carpeta, iniciá un servidor estático con Python 3:

   ```sh
   python -m http.server 8000
   ```

   En Windows también podés usar `py -m http.server 8000`.

3. Abrí <http://localhost:8000> en el navegador.
4. Para detener el servidor, presioná `Ctrl+C` en la terminal.

## Comprobar cambios

Antes de publicar cambios, revisá la página en pantallas de escritorio y de celular, y comprobá los enlaces y la carga de los estilos e imágenes.
